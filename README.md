# Dodge Drop

Dodge falling obstacles, survive as long as you can, and beat your high score.

**Live:** https://dodge-drop.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `dodge-drop`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
